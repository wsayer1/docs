## Registering for an event

Open any event page and click **Register**. You need to be signed in — if you're not, the button reads **Sign in to register** and takes you to the sign-in page first.

What happens next depends on the event:

- **Spots available** — you're confirmed instantly and the page shows **You're going**.
- **Event is full** — the button reads **Join waitlist**. You're added in order, and the page shows **You're on the waitlist**.

## How the waitlist works for you

You're in a queue, first come, first served. When a confirmed guest cancels, the person at the front of the waitlist is automatically given the open spot — no action needed on your part.

<Note>
  Gatherly doesn't send emails yet (coming soon), so check the event page or **My tickets** to see if you've been promoted. Your badge switches from **Waitlisted** to **Going**.
</Note>

## Cancelling your registration

On the event page, click **Cancel registration**. This works whether you're confirmed or waitlisted:

- If you were confirmed, your spot opens up and the first waitlisted guest gets it.
- If you were waitlisted, you simply leave the queue.

You can register again later if you change your mind — but if the event filled up in the meantime, you'll join the back of the waitlist.

## When registration isn't possible

- **The event has ended** — past events show "This event has ended."
- **The event was cancelled** — cancelled events no longer accept registrations.
- **The event is a draft** — drafts are only visible to their host.
