Click **Create event** in the header to open the event form. Here's what each part does.

## Event details

| Field | What it does |
| --- | --- |
| **Event title** | The headline guests see everywhere — on Explore, on tickets, and on the event page. |
| **Description** | Tell guests what to expect. Line breaks are preserved, so you can structure it freely. |
| **Cover image URL** | Optional. Paste a link to an image and it becomes the banner at the top of your event page. Without one, Gatherly shows a tasteful colored cover. |
| **Starts / Ends** | The start time is required; the end time is optional. |

## In person or online

Choose where the event happens:

- **In person** — enter the venue or address. It's shown to everyone on the event page.
- **Online** — paste the meeting link (Zoom, Meet, or anything else). The link is never shown publicly: only you and registered, confirmed guests can see it. Waitlisted guests see it once they're promoted to a confirmed spot.

## Capacity

Leave capacity empty for unlimited spots. Set a number to cap attendance — once that many guests are confirmed, new registrations automatically join a [waitlist](/hosting/capacity-and-waitlist).

## Visibility

- **Public** — the event is listed on the Explore page for everyone to find.
- **Private** — the event is hidden from Explore; only people you share the link with can find and register for it.

More on this in [Public and private events](/hosting/public-and-private-events).

## Drafts vs. published

- **Save as draft** keeps the event visible only to you. It won't appear on Explore and nobody can register. You can come back and edit it any time from **My events**, where drafts have their own section.
- **Publish event** makes it live immediately. Guests can open the page and register right away.

<Note>
  Once an event is published, it can't go back to being a draft — but you can still [edit its details or cancel it](/hosting/edit-or-cancel).
</Note>
